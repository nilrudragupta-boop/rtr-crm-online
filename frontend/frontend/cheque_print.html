Disclaimer

This software is designed solely to print user-entered details such as Payee Name, Amount, Date, and "A/C Payee Only" on pre-printed bank cheques.

Please note that bank details, MICR code, IFSC code, cheque number, and other security features are not printed by this software, as these elements are already pre-printed by the issuing bank.

Some users may mistakenly assume that the software prints an entire cheque. This is not the intended functionality. The Cheque Printing Module is designed only to fill the required information on existing bank-issued cheques and does not generate or print a complete cheque. This approach is consistent with standard cheque-printing software practices and aligns with applicable banking procedures and guidelines.

By using this software, users acknowledge and understand that it is intended exclusively for printing information on valid, pre-printed bank cheques.
